# Demo Click Path

Use this path for a 10-minute executive walkthrough. Open create workflows only
briefly to show guided operating discipline; do not spend the demo filling forms.

1. `/command-center` - executive cockpit and D5O control.
2. `/pipeline` - pursuit discipline and bid risk.
3. `/pipeline/new` - guided opportunity intake preview.
4. `/projects` - D2 contract baseline.
5. `/projects/new` - guided project setup preview.
6. `/mobilization` - D3 field readiness.
7. `/mobilization/new` - guided mobilization plan preview.
8. `/field-execution` - D4 daily control.
9. `/field-execution/daily-report/new` - guided daily report preview.
10. `/rfis-submittals` - information control.
11. `/changes` - commercial recovery control.
12. `/billing` - pay application and cash-at-risk visibility.
13. `/safety` - safety control.
14. `/quality` - quality control.
15. `/closeout` - D5 acceptance package readiness.
16. `/reports` - Optimize intelligence loop.
17. `/admin` - enterprise readiness, route safety, RBAC, audit, persistence plan.
